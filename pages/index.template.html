Install

Install the proabono tool once. In any Proa site, add components by name. Dependencies come along, and every file is checked against its SHA-256 before anything is written.

  1. Install the installer.

    cargo install --git {{REPO}} proabono

  2. Add components from inside your Proa site.

    proabono add {{ALL}}

  3. Link the stylesheet and runtime once in src/layouts/root.rs, after your own stylesheet.

    <link rel="stylesheet" href="/static/proa/proabono/proabono.css" />
<script src="/static/proa/proabono/proabono.js" defer></script>
